# 중학교 수학 보드게임 확장 기록

2026-10-12 갱신 · JB Math

## 2026-10-12 반영

요청 순서대로 프라임 클라임 → 기존 세 게임 모드 보강 → 목록·캐시 통합을 진행했다.

- **프라임 클라임** (`math-game/prime-climb/`): 두 말·101 도착·사칙연산·차례 끝 충돌·더블 네 번 사용을 구현한 수업용 기본판. 원작 Prime Cards는 제외하며 화면에 명시한다. 소인수 표시, 연습 1~3단계, AI 3단계, 같은 기기 2인 제공.
- **SET** (`math-game/set-game/modes.html`): 3속성에서 4속성으로 이어지는 연습, 탐색할 카드 쌍의 수가 다른 AI, 각자 12차례 순차 대결. 원작 동시 속도 경쟁과 구분한다. 기존 index.html의 학급용·수학 학습 화면 유지.
- **마이너스 경매** (`math-game/minus-auction/modes.html`): 기존 음수 점수 규칙을 따른 2인 변형. 카드 33장·칩 30개·낙찰 후 상대 차례. 연습은 즉시 점수 변화 비교이고 AI는 덱 순서를 읽지 않는다. 기존 다인 학급 화면 유지. No Thanks! 원작의 3~7인 규칙과 동일하다고 표시하지 않는다.
- **쿼리도** (`math-game/quoridor/`): 9×9·벽 10개, 직선/옆 점프, 벽 중복·교차·완전 차단 금지. 연습 3단계, AI 3단계, 같은 기기 2인. 수업 시간을 위해 동일 상태 3회 반복 또는 160차례에서 무승부. 기존 game 저장소 버전은 하단에 연결.
- 공통 화면은 `math-game/boardgame-kit/`. 힌트·되돌리기·모드 변경·새 게임·차례·결과를 제공한다. 네 게임은 모두 공개 정보 게임이므로 패 가림 화면이 필요하지 않다. 모드 변경·새 게임·되돌리기는 대기 중 AI 동작을 취소한다.
- 목록은 **플레이 가능한 게임 또는 수업용 변형 5종**, 제작 예정 13종으로 표시한다. 프라임 클라임은 이벤트 카드 없는 기본판이고 No Thanks! 항목은 마이너스 경매 변형이다. 다음 신규 게임은 로스트 시티.
- 메인 게임 카드, 안내, 기존 화면의 모드 진입 링크, 버전이 붙은 파일 요청까지 오프라인 캐시에 반영한다. 오프라인은 인터넷 접속 상태에서 서비스 워커 설치가 끝난 기기에서 사용할 수 있다. 원작 외부 링크에는 인터넷이 필요하다.
- 검증: `node --test tests/boardgame-expansion.test.js`의 핵심 규칙 10개 통과. 정수 이동, 차례 끝 충돌, 연습 해답, SET 쌍의 완성 카드, 점수 연결, 칩 보존, 점프와 경로 보장 등을 검사한다. 브라우저 수동 플레이·실기기·오프라인 실행은 미검증이다.

## 2026-10-09 반영 기록

- 게임탭: `attribute-four`, `middle-boardgame-collection` 카드 추가.
- `math-game/boardgame-library/`: 공식 제작사·출판사 자료를 바탕으로 출시 게임 18종 목록, 권장 학년, 성취기준, 수업 질문, 원작 링크, 제작 순서 제공.
- `math-game/attribute-four/`: 콰르토의 기본 규칙을 참고한 독자 코드·그래픽의 수업용 구현. 새로 플레이할 수 있는 게임은 이 1종이다.
- 기존 세트, 마이너스 경매, 외부 쿼리도는 관련 활동으로 연결한다. 새 모드 기준을 이미 충족한다고 표시하지 않는다.
- 게임탭 안내문·오프라인 캐시 갱신. 별도 외부 라이브러리, 로그인, 서버, API 키가 필요하지 않다.
- 사용자의 요청에 따라 실행·브라우저·게임 동작 테스트는 수행하지 않았다. 실제 수업 전 동작 검증 완료를 주장하지 않는다.

## 공통 설계 요구

1. **연습**: 짧은 규칙 학습, 단계 또는 문제 난이도, 힌트, 선택 결과 설명.
2. **싱글플레이**: AI와 대결. 쉬움·보통·어려움. 점수 조작 없이 전략·탐색 수준을 바꾼다.
3. **대결**: 한 기기를 두 사람이 번갈아 조작한다. 온라인 방이나 원격 멀티플레이를 전제로 하지 않는다. 비공개 패가 있는 게임에는 기기 전달·패 가림 단계를 둔다.
4. 기존 게임의 모드 선택, 차례 표시, 규칙 안내, 되돌리기, 수학 설명 흐름을 참고한다.
5. 원작 정보는 출처로 연결하고, 그래픽·문제·UI·설명·코드는 직접 작성한다. 원작과 다른 규칙은 해당 화면에 명시한다.

## 첫 게임: 속성 사목 · 콰르토

- 4×4 판, 16종의 말, 색·모양·높이·윗면의 이진 속성.
- 말을 고르는 사람과 놓는 사람이 다르다. 놓은 사람이 다음 말을 고른다.
- 가로·세로·대각선의 네 말에 공통 속성이 있으면 놓은 사람이 승리한다.
- 원작의 승리 선언 대신 자동 판정한다. 고급 2×2 사각형 승리 규칙은 제외한다.
- 연습 1~3단계: 유효한 완성 수가 있는 판 생성, 틀린 선택 후 재시도, 여러 정답 허용, 완성 속성 설명.
- AI 쉬움: 무작위 중심. 보통: 즉시 승리와 위험한 말 판단. 어려움: Worker에서 시간 제한을 둔 반복 심화 탐색. 완벽한 AI라는 주장은 하지 않는다.
- Worker를 사용할 수 없는 환경에서는 기본 전략 AI로 진행하며 안내한다.
- 2인: 공개 정보로 같은 화면을 순차 조작. 되돌리기와 힌트를 학습용으로 허용한다.
- 분석의 위험한 말 비율은 남은 말에서 균등하게 뽑는 가상의 비율이며 AI 승률이 아니다.

## 교육과정 해석

[NCIC 수학과 교육과정 원문](https://ncic.re.kr/inv/org/download.do?orgType=ogi4&seq=10003559&year=2022), [교육부 고시 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)를 기준으로 한다.

국가 성취기준은 중학교 1~3학년군이다. 목록의 학년은 일반적인 교과서 단원 배치를 참고한 **권장 배치**다. 특정 게임이 국가 교육과정에서 지정되었다는 의미는 없다. 적용 시기는 중1 2025년, 중2 2026년, 중3 2027년이다.

기본 규칙 자체의 수학과 교사가 추가하는 탐구를 구분한다. 중3은 여러 판의 결과를 모은 뒤 분산·표준편차 [9수04-07], 공학 도구를 활용한 상자그림 [9수04-08] 등으로 확장한다. 중학교 경우의 수 [9수04-05]는 합·곱의 법칙 수준으로 다루며 순열·조합 공식을 필수로 요구하지 않는다. SET·콰르토의 속성 분류를 중학교 집합·명제 단원으로 표시하지 않는다.

## 다음 게임을 추가할 때

- 독립 디렉터리에 규칙·AI·UI를 분리하고, 이 문서의 공통 모드를 적용한다.
- `data.js`의 상태를 실제 완성 범위에 맞게 바꾸고 실행 링크를 연결한다.
- 메인 `index.html`에 게임 카드, 필요하면 `assets/app.js`에 실행 안내를 추가한다.
- 로컬 자원을 `sw.js`에 반영하고 캐시 버전을 갱신한다.
- 테스트 수행 여부는 실제로 수행한 범위 그대로 기록한다. 자동 배포 완료와 게임 동작 검증 완료를 구분한다.
