새 주문방 만들기

메뉴판 사진을 올리거나 메뉴를 직접 입력하고, 링크를 공유해 각자 스마트폰에서 주문하세요. 이름·메뉴별 합계는 모든 참여자가 함께 봅니다.

실시간 공유에는 Firebase 연결이 필요합니다. 아래에 Firebase 웹 앱 설정 코드를 그대로 붙여 넣으세요. 데이터베이스 규칙 등은 설정 안내를 참고하세요. 설정 전에는 다른 휴대전화와 주문이 동기화되지 않습니다.

Firebase 콘솔의 프로젝트 설정 → 일반 → 내 앱 → SDK 설정 및 구성 → 구성에 보이는 코드를 그대로 전체 복사해서 붙여 넣으세요. JSON으로 직접 바꿀 필요가 없습니다.

사용 안내

메뉴와 가격은 방장만 수정합니다. 참여자는 자신의 주문을 수정·삭제할 수 있습니다. 모든 주문은 참여자들에게 실시간 공개됩니다. 실제 매장 결제와 연동되는 서비스가 아닙니다.

가격에 없는 추가 옵션은 직접 적을 수 있으나 추가 금액은 자동 계산되지 않습니다. 방을 마감하면 주문 수정이 중지됩니다.
